# Jogo Pedro – Diversidade & Direitos

Jogo educativo em HTML, CSS e JavaScript com 3 painéis sequenciais:

1. **Questões de gênero** – ligue cada imagem ao texto correto.
2. **Movimento LGBTQIA+** – quiz de múltipla escolha.
3. **Movimento trabalhista** – coloque os eventos em ordem cronológica.

## Como jogar

Abra o `index.html` no navegador. Não precisa instalar nada.
